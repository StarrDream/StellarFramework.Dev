# StellarFramework 快速开始

这份文档只负责让新人先跑通框架。深度功能说明请进入 Kit 说明文档；源码实现请进入对应源码文档。

## 第一次打开项目

1. 打开 Unity 菜单 `StellarFramework -> Tools Hub`。
2. 在左侧进入 `Start Here -> Quick Start`。
3. 打开 `Assets/StellarFramework/Samples/TankArena/Scene/FrameworkDemo.unity`。
4. 运行坦克 Demo：左侧控制区移动，右侧控制区独立瞄准和开火；坚持战斗、收集维修核心，直到战局结束。
5. 在右上方切换语言与自动/手动开火，打开 **SYSTEMS / 系统** 查看状态、事件和 Kit 连接；重新开始一局后，最高分仍会保存在本机。
6. 这是本地编辑器预览。需要验证真实热更包时运行 Android 或 Windows HotUpdate Release Gate，再按项目需要进入对应 Kit Guide。

## 新项目默认选择

- 架构：用 `Architecture<T>` 管 Model、Service、View。
- UI：中大型项目可由 `UIKit` 管理面板生命周期；游戏 HUD 也可以使用 Unity UI 与 UIAdaptationKit 组合，按项目规模选择。
- 资源：只从 `ResKit` 分配 loader，不让业务直接关心 Resources、AB、AA。
- 内容热更：这是可选能力。生产项目推荐由 YooAsset 负责 Package 版本、Manifest、下载与缓存，业务资源访问仍统一经过 ResKit。
- 代码热更：这是 ResKit 的可选扩展。导入 `ResKit.CodeUpdate.HybridCLR` 后，由项目从 ResKit 获取 Provider、传入 `ResScope`，再加载 `HotUpdateManifest.json`、DLL 和 AOT metadata。
- 配置、设置、音频、事件：按 `ConfigKit`、`SettingsKit`、`AudioKit`、`EventKit` 的说明文档接入。

## 架构最小模板

```csharp
using StellarFramework;
using UnityEngine;

public sealed class GameApp : Architecture<GameApp>
{
    protected override void InitModules()
    {
        RegisterModel(new PlayerModel());
        RegisterService(new PlayerService());
    }
}

public interface IReadOnlyPlayerModel : IReadOnlyModel
{
    int Hp { get; }
}

public sealed class PlayerModel : AbstractModel, IReadOnlyPlayerModel
{
    public int Hp { get; set; } = 100;

    int IReadOnlyPlayerModel.Hp => Hp;
}

public sealed class PlayerService : AbstractService
{
    public void TakeDamage(int damage)
    {
        PlayerModel model = GetModel<PlayerModel>();
        model.Hp = Mathf.Max(0, model.Hp - damage);
    }
}

public sealed class GameEntry : MonoBehaviour
{
    private void Awake()
    {
        GameApp.Interface.Init();
    }
}
```

View 通过只读接口读取 Model，并调用 Service 修改数据：

```csharp
using StellarFramework;
using UnityEngine;

public sealed class PlayerHudView : StellarView
{
    public override IReadOnlyArchitecture Architecture => GameApp.Interface;

    public override void OnBind()
    {
        RefreshHp();
    }

    public void OnClickDamage()
    {
        this.GetService<PlayerService>()?.TakeDamage(10);
        RefreshHp();
    }

    private void RefreshHp()
    {
        IReadOnlyPlayerModel model = this.GetReadOnlyModel<IReadOnlyPlayerModel>();
        if (model != null)
        {
            Debug.Log($"当前血量: {model.Hp}");
        }
    }

    public override void OnUnbind()
    {
    }
}
```

## UIKit 最小模板

```csharp
using Cysharp.Threading.Tasks;
using StellarFramework.UI;
using UnityEngine;

public sealed class LoginPanelData : UIPanelDataBase
{
    public string DefaultAccount;
}

public sealed class LoginPanel : UIPanelBase
{
    public override void OnOpen(UIPanelDataBase data)
    {
        if (TryGetPanelData<LoginPanelData>(data, out LoginPanelData loginData))
        {
            Debug.Log(loginData.DefaultAccount);
        }
    }
}

public sealed class UIEntry : MonoBehaviour
{
    private async UniTaskVoid Start()
    {
        await UIKit.Instance.InitAsync();
        await UIKit.OpenAsync<LoginPanel>(new LoginPanelData { DefaultAccount = "player01" });
    }
}
```

## ResKit 最小模板

```csharp
using Cysharp.Threading.Tasks;
using StellarFramework.Res;
using UnityEngine;

public sealed class PrefabSpawner : MonoBehaviour
{
    private IResLoader _loader;
    private const string PrefabPath = "Assets/Game/Prefabs/Hero.prefab";

    private async UniTaskVoid Start()
    {
        _loader = ResKit.Allocate(ResLoaderRequest.Custom("Addressables", nameof(PrefabSpawner)));
        GameObject prefab = await _loader.LoadAsync<GameObject>(PrefabPath, destroyCancellationToken);

        if (prefab != null)
        {
            Instantiate(prefab);
        }
    }

    private void OnDestroy()
    {
        if (_loader == null)
        {
            return;
        }

        _loader.Unload(PrefabPath);
        ResKit.Recycle(_loader);
        _loader = null;
    }
}
```

## 热更新最小路线

StellarFramework 把“内容热更新”和“代码热更新”分开：

1. 调用 `YooAssetResKitInstaller.InstallLoader()` 注册 YooAsset Loader，再调用 `YooAssetContentUpdateInstaller.Install()` 注册资源内容更新 Provider。两个扩展可以分别替换。
2. 从 ResKit 获取内容更新 Provider 并调用 `UpdateAsync`；YooAsset 负责初始化 Package、检查版本、更新 Manifest、下载和缓存。
3. 更新成功后，通过 `ResKit.CreateCustomScope(...)` 创建代码资源 Scope。
4. 从 ResKit 获取 `IResCodeUpdateProvider`，并把 Scope 传给 Provider。
5. Provider 通过该 Scope 读取 `HotUpdateManifest.json`、热更 DLL 和 AOT metadata，校验后加载代码并进入热更入口。

Addressables 在框架中只作为 ResKit 的可选 Load / Release 后端与本地 Player Content 构建入口，不再承担 StellarFramework 的正式资源热更新工作流。

继续阅读：[ResKit.CodeUpdate.HybridCLR 使用说明](../02-Kits/Reskit/CodeUpdate/HybridCLR/ResKit-CodeUpdate-HybridCLR-说明文档-Guide.md) 和 [源码说明](../02-Kits/Reskit/CodeUpdate/HybridCLR/ResKit-CodeUpdate-HybridCLR-源码文档-Guide.md)。

## 常见排错

- Tank Arena 场景缺失：检查 `Assets/StellarFramework/Samples/TankArena` 是否完整导入，并确认 Unity 已完成导入与脚本编译。
- UI 打不开：检查 `UIKitSettings`、`UIRoot`、面板 Prefab 路径和加载后端。
- Addressables 同步加载返回空：生产 AA 使用 `LoadAsync<T>`。
- AB 加载失败：先运行 ToolsHub 的 `资源打包 (AssetBundle)`，再确认 `AssetBundleManager.InitAsync()` 已执行。
- 内容更新没生效：先检查 YooAsset Package 初始化、版本、Manifest 与 Downloader 是否完成，再确认对应 ResKit Loader 已注册。
- DLL SHA256 mismatch：重新执行 HybridCLR DLL 导出，并确保 Manifest、DLL、metadata 被同一个内容版本一起发布。

## 生产热更新规则

- 编辑器和 Development Build 允许开发期诊断；正式发布构建会启用严格的 DLL SHA256 校验。
- `HotUpdateManifest.json`、`HotUpdate.dll.bytes` 和全部 AOT metadata 必须由同一个 ResKit 内容版本提供。
- 每次代码热更发布都先通过 Tools Hub 重新导出 DLL、metadata 与 Manifest，再交给 YooAsset 内容管线一起发布。
- 生产放行前必须在目标平台的 IL2CPP Player 上完成真实内容更新、SHA 校验、metadata 加载、热更入口执行和失败/回滚验证；编辑器检查不能替代这一步。
